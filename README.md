# PlanetExpress

## Overview

PlanetExpress is an academic Java application developed
individually as part of my Software Engineering degree
at Universidad Politécnica de Madrid (UPM).

The application simulates a space transportation 
management system, applying object-oriented programming
principles to manage customers, spacecraft, spaceports,
bookings and shipments.

## Main Features

- Customer management.
- Spacecraft and spaceport management.
- Shipment search, booking and cancellation.
- Availability and capacity management.
- Invoice generation.
- CSV-based data persistence.
- Console-based user interaction.

## Project Structure

- `src/` - Java source code.
- `clientes.csv` - Customer data.
- `naves.csv` - Spacecraft data.
- `puertos.csv` - Spaceport data.
- `envios.csv` - Shipment data.
- `portes.csv` - Transportation data.
- `factura.txt` - Invoice output.
- `lista.txt` - Text output file.

## Getting Started

1. Clone the repository:

   git clone https://github.com/pauumoreno/PlanetExpress.git

2. Open the project in IntelliJ IDEA.
3. Configure a compatible Java SDK.
4. Locate the main class in the src directory.
5. Run the application from IntelliJ IDEA.

Ensure that the required CSV files are available in
the project's working directory.
